Gestaopsi

Política de Privacidade

Atualizada em 11 de novembro de 2026.

O Gestaopsi (omatsaldanha.com/consultorio) é um sistema administrativo para psicólogas e psicólogos: agenda, cobranças, despesas, recibos do Receita Saúde e organização de conteúdo. Ele é mantido por Matheus Saldanha, de Pelotas/RS. Contato: contato@omatsaldanha.com.

Papéis na LGPD

A psicóloga ou o psicólogo que usa o Gestaopsi é o controlador dos dados dos próprios pacientes. O Gestaopsi atua como operador: guarda e processa esses dados só para fazer o sistema funcionar para quem cadastrou.

Quais dados ficam guardados

  • Da conta: nome, e-mail, CRP e, se preenchido, CPF (usado só para gerar o arquivo de lote do Receita Saúde).
  • Dos pacientes, cadastrados pelo profissional: nome, CPF, WhatsApp, responsável, quem paga, valor e horário das sessões, pagamentos, status dos recibos e um link opcional para a pasta de documentos no Google Drive do profissional.
  • Despesas do consultório, referências de conteúdo e o briefing de posicionamento.

O Gestaopsi não é prontuário. O sistema avisa para não registrar informação clínica, e nenhum campo foi feito para isso.

Onde os dados ficam

No Supabase (banco de dados em São Paulo, Brasil), com acesso protegido por login e regras que deixam cada profissional ver só os próprios dados. O site é servido pela Vercel. Nada é vendido nem usado para anúncio.

Integração com o Google Agenda

Se o profissional escolher conectar o Google Agenda, o Gestaopsi pede duas permissões:

  • Criar agendas secundárias e gerenciar os eventos delas (calendar.app.created): o Gestaopsi cria uma agenda chamada “Gestaopsi” na conta do profissional e coloca nela as sessões. Ele não lê nem altera nenhuma outra agenda.
  • Ver a disponibilidade (calendar.freebusy): o Gestaopsi vê só os horários ocupados da agenda principal, sem título, descrição ou participantes, para mostrar esses blocos como “ocupado” na agenda do sistema.

Por padrão, o evento leva só as iniciais do paciente; o nome completo só vai se o profissional escolher. O acesso fica no navegador do profissional por até 1 hora e não é guardado no servidor. Dá para desconectar a qualquer momento no Gestaopsi ou em myaccount.google.com/permissions.

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

Serviços externos

Para mostrar foto de perfil de creators e o preview de posts, o navegador carrega imagens e incorporações do Instagram, TikTok, YouTube e unavatar.io. Esses serviços recebem o endereço IP de quem está vendo a página, como em qualquer site.

Por quanto tempo

Enquanto a conta existir. Ao pedir a exclusão da conta pelo e-mail acima, todos os dados dela são apagados em até 30 dias, exceto o que a lei obrigar a guardar.

Teus direitos

Confirmar o tratamento, acessar, corrigir, exportar e excluir os dados, e revogar consentimentos (LGPD, art. 18). É só escrever para contato@omatsaldanha.com.
